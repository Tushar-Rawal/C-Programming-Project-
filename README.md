# Smart Parking Management System

## Project Overview
The Smart Parking Management System is a C and MySQL based project
designed to manage vehicle parking efficiently.

## Technologies Used
- C Programming
- MySQL Database
- MySQL C API
- VS Code

## Features
1. Park a vehicle.
2. View parking slot availability.
3. Remove a vehicle.
4. Calculate parking fees.
5. Store parking records in MySQL.
6. Maintain Paid and Pending payment status.
7. Prevent duplicate vehicle parking.
8. Display parking history.

## Parking Capacity
- Total Slots: 10
- Two-Wheeler Slots: 5
- Four-Wheeler Slots: 5

## Parking Charges
- Two-Wheeler: Rs. 20 per hour
- Four-Wheeler: Rs. 40 per hour

## Database Tables
- parking_slots
- vehicles
- payments
- parking_records

## How to Run
Compile the C program using the MySQL client libraries,
then execute the generated program.
